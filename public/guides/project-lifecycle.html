How an L&D project moves through Tempo

Every new project follows the same five phases, from the first discovery call to the lessons-learned close-out. This guide shows what happens in each phase, how a module goes from storyboard to sign-off, who clicks which button, and what you'll see on your dashboard.

For: L&D team, project owners, reviewers Applies to projects created on or after 13 Oct 2026 Older projects work as before

2 · Design and build

A module, step by step

Each module is one chain of six tasks. A review or sign-off can pass the work forward or send it back For Revision. That loop is how we iterate, SAM-style, without reopening anything.

Passes forward when the step is done Sent back For Revision with a comment
3 · Hand-offs

Next step buttons: who clicks what

On new projects the Next step column tells you what to do. Status can still be changed in Tasks, but the buttons keep the review chain intact.

You seeOnWho clicks itWhat happens
→ Ready for ReviewWork a review depends on (storyboard, build, scope statement)The assigneeChecks Logged hours and Output Count, marks it Done, and hands it to the reviewer. Shows In review · name.
✓ Pass QAReview stepsThe reviewerMarks the review Done. The sign-off unlocks.
✓ ApproveSign-off stepsThe approverMarks the sign-off Done. The next phase's work unlocks and the milestone moves.
↺ For RevisionReview and sign-off stepsThe reviewer or approverAsks for a comment, sends the work back to In Progress, and adds 1 to its revision count. The owner sees it under Sent back to you.
WaitingAny step whose earlier step isn't doneNobody yetShows who it's waiting on and when it should be ready. It isn't on your to-do list yet.
Finishing a task always opens the same Complete task pop-up: Reported Completion date, Work Type, Output Type, Output Count and Logged hours, with + Log time if hours are missing. Work Type and Output Type changes are kept in the Audit Trail.

6 · The WBS page

Working in the WBS

Phase progress

A card per phase shows % done, counting real tasks only. Click a card to show only that phase; click again for all.

Filters

Search, Phase, Module, Status, Assignee and Work Type. While a filter is on, reordering and adding are paused. Use Clear to get everything back.

Column views

  • Essential: who, status, hours, start and end
  • Planning: adds Work Type, Output Type, Duration
  • Full: every column

Group by Module

Lists each module from storyboard to sign-off, with its progress and current stage. Switch back to Phase any time.

Timeline

The Gantt has its own tab on the project Overview and the WBS, in phase colours. Change dates on the WBS tab.

Moving tasks

Move up / down stays inside a phase. To change a task's phase, use the row menu › Move to phase.

7 · Good habits

Habits that keep the plan honest

Owners

  • Pick phases and apply templates in Draft, then delete what the project doesn't need.
  • Add one module per lesson or course piece, named the way the team talks about it.
  • Use the Planning view to fill Work Type and Output Type before Start Project.
  • Link each milestone to the tasks that must finish first.

Everyone

  • Log time as you go, so Ready for Review isn't blocked by missing hours.
  • Give a clear, specific comment with For Revision: what to change and why.
  • Check Waiting for you first thing; reviews hold up other people.
  • Use the Complete pop-up's date for when the work actually finished.
